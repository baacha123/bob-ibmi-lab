### TEACHING NOTE - introduce IFS early (place at 00-04-connected-panels.png)
Explain the IBM i's two file worlds when the panels first appear:
- QSYS = libraries/objects/source members (where RPG lives: SANDBOX/QRPGLESRC). The classic filing cabinet.
- IFS (Integrated File System) = regular folders/files like a Mac/Windows file explorer (/home/U4YNIPH). The IFS Browser panel browses these.
- Why reports save to IFS: markdown/.md, PDFs, HTML, logs are STREAM FILES, which live in the IFS (not QSYS members). So Bob saves the business-rules .md to an IFS path and you open it from the IFS Browser.
Pays off at 02-07 (save to /home/U4YNIPH/sandbox/docs/business-rules/CREDASM-business-rules.md).
